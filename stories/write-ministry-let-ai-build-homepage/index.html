SO DO NOT FEAR · 2026-11-17 · 2분 읽기

교회 담당자는 홈페이지를 관리하기 위해 글을 다시 쓰고, 사진을 고르고, 여러 채널에 같은 내용을 반복해서 올립니다. 작은 교회일수록 이 일이 사역의 시간을 빼앗습니다.

먼저 교회가 쓰세요

‘이번 주일 오전 11시 예배, 요한복음 15장, 예배 후 청년 모임’처럼 평소 말하듯 내용을 남기면 됩니다. 완벽한 홍보 문장을 만들 필요가 없습니다.

AI가 홈페이지 언어로 바꿉니다

AI는 입력된 내용을 홈페이지 공지, 주보 요약, 카카오톡 안내, SNS 게시물, 새가족 질문과 답변으로 나눠 정리합니다. 한 번의 기록이 여러 접점으로 이어집니다.

사람의 확인이 마지막 단계입니다

AI가 목회적 판단을 대신하거나 교회의 신앙고백을 새로 만들지 않습니다. 담당자가 사실과 표현을 확인한 뒤 공개합니다. 민감한 상담 내용과 개인정보는 입력하지 않고, 필요한 경우 사람에게 연결합니다.

홈페이지를 만드는 일보다 중요한 것은 교회의 사역이 계속 기록되고 사람에게 닿는 일입니다. 검색 노출과 콘텐츠 형식은 AI에게 맡기고, 교회는 예배와 돌봄과 선교에 집중할 수 있습니다.
