AI에 입력해도 되는 교회 자료, 멈추고 확인해야 하는 자료

공개 여부와 식별 가능성을 살펴보고, 실제 사연 대신 연습용 자료로 작업하는 입력 전 점검표입니다.

SO DO NOT FEAR · 2026-11-20 · 3분 읽기

AI로 공지나 문서를 정리할 때 “이 자료를 넣어도 될까?”라는 질문이 먼저 필요합니다. 복사해 붙이는 순간 자료가 외부 서비스로 전달될 수 있기 때문입니다. 여기서는 법적 허용 여부를 판정하는 대신, 담당자가 입력을 멈추고 검토할 수 있도록 자료를 나누는 운영 방법을 제안합니다. 실제 사용은 교회의 정보 관리 기준과 해당 서비스의 현재 조건을 함께 확인해야 합니다.

공개된 자료도 목적과 권리를 확인합니다

이미 공개한 행사 안내는 업무 연습에 사용할 후보가 될 수 있습니다. 그래도 다른 사람의 사진이나 글, 개인 연락처가 섞여 있는지 살핍니다. 인터넷에서 볼 수 있다는 사실만으로 모든 외부 서비스에 다시 입력해도 된다는 결론을 내리지는 않습니다. 필요한 항목만 따로 정리하는 편이 검토 범위를 줄입니다.

비공개 정보는 일단 입력을 멈춥니다

교인 명부, 출석 기록, 상담 내용, 개인 기도제목과 후원자 명단은 일반 공개용 작업에 그대로 넣지 않습니다. 이름을 지웠더라도 직분, 지역, 가족 관계와 구체적인 사건이 남아 있으면 사람을 알아볼 수 있습니다. “익명으로 바꿨다”는 이유만으로 안전하다고 단정하지 않습니다.

비밀번호, 인증키와 계정 복구 정보는 질문을 돕는 자료로 보내지 않습니다. 화면 캡처를 공유할 때에도 주소창, 계정명과 주변 메시지를 함께 확인합니다. 필요한 업무가 실제 개인정보 처리를 포함한다면 기관 책임자와 적합한 환경·절차를 먼저 정해야 합니다.

연습은 사실적인 가상 자료로 합니다

예를 들어 표 정리 방법을 배우려면 실존 교인 목록 대신 “연습용 자료”라고 표시한 임의의 항목을 씁니다. 칼럼이나 간증의 사실 자료로 재사용하지 않도록 가상 자료임을 남깁니다. 자료 구조와 정리 규칙만으로 질문할 수 있다면 실제 내용은 보내지 않습니다.

입력 전에 네 가지를 적어봅니다

어떤 목적에 쓰는지, 꼭 필요한 정보는 무엇인지, 어디로 전달되는지, 누가 확인했는지를 적습니다. 서비스별 저장·학습·공유 설정과 삭제 방법은 현재 공식 안내를 확인합니다. 화면 이름이나 조건이 달라질 수 있으므로 오래된 강의 화면만 믿지 않습니다.

실수로 중요한 정보를 보냈다면 추가 입력을 멈추고 기관 책임자에게 알립니다. 삭제 기능 확인과 접근 정보 변경 등은 정보 종류에 맞춰 대응하며, 이미 전송한 정보가 완전히 회수됐다고 단정하지 않습니다. 첨부 점검표는 동의서나 법률 검토의 대체물이 아니라 입력 전 확인을 돕는 운영 도구입니다.
