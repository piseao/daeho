교회 홈페이지 담당자가 바뀔 때 넘겨야 할 것들

계정·도메인·콘텐츠·비용·복구 방법을 정리하고 다음 담당자가 직접 수정해보는 인수인계 양식입니다.

SO DO NOT FEAR · 2026-11-20 · 3분 읽기

홈페이지를 오래 운영하려면 다음 담당자가 이어받을 수 있어야 합니다. “필요하면 연락하세요”라는 말만으로는 계정 만료와 갑작스러운 수정에 대응하기 어렵습니다. 인수인계는 파일을 보내는 일뿐 아니라 다음 사람이 실제로 접근하고 작업할 수 있는지 확인하는 과정입니다.

소유권과 접근 권한부터 확인합니다

도메인 등록 기관, 호스팅, 저장소, 게시 도구와 연결된 외부 서비스를 적습니다. 기관 소유 계정인지 개인 계정인지, 누가 접근 권한을 줄 수 있는지 확인합니다. 소유권 변경이 필요하면 각 서비스의 공식 절차를 따릅니다. 비밀번호와 복구 코드를 공개 문서나 공용 채팅에 붙이지 않습니다.

이전 담당자의 접근을 먼저 끊기보다 새 담당자의 로그인과 필요한 역할을 확인한 뒤 정리할 권한을 합의합니다. 보안 문제 등 즉시 차단이 필요한 상황은 기관 책임자와 별도로 처리합니다.

반복 작업과 갱신 일을 기록합니다

예배 시간 수정, 공지 게시, 사진 교체와 게시 취소처럼 자주 하는 작업의 위치와 순서를 남깁니다. 도메인·유료 서비스의 갱신일, 결제 주체와 연락받을 주소도 확인합니다. 카드번호 자체를 기록할 필요는 없습니다. 원본 사진과 공개 가능 여부, 문의 폼의 수신 위치도 함께 정리합니다.

새 담당자가 작은 작업을 직접 해봅니다

연습용 공지 하나를 미리 보고, 수정한 뒤 공개 여부를 확인합니다. 문제가 생기면 이전 버전이나 백업에서 어떻게 복구하는지 함께 살핍니다. 원본 내용과 공개 화면이 어떻게 연결되는지 이해해야 같은 실수를 반복하지 않을 수 있습니다. 이름만 적힌 문서보다 직접 완료해본 작업이 인수인계의 상태를 더 잘 보여줍니다.

지원 종료와 남은 문제를 분명히 합니다

미해결 오류, 정리하지 못한 계정과 추가 확인이 필요한 항목을 감추지 않습니다. 지원받을 연락 경로와 시간, 유료 유지보수 범위가 있다면 함께 적습니다. 마지막으로 필요한 접근 권한만 남았는지 점검합니다.

첨부한 양식은 서비스 목록과 실제 작업 확인, 미해결 사항을 한 문서에 정리하도록 구성했습니다. 특정 담당자의 기억에 기대던 운영을 공동체의 기록으로 옮기는 일은 다음 사람의 수고를 덜어주는 실제적인 섬김입니다.
