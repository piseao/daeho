공지 한 장을 홈페이지·SNS·주보로 바꾸는 방법

기준 원문 하나로 채널별 안내를 만들고 날짜·장소·신청 링크의 불일치를 줄이는 요청문과 검토표입니다.

SO DO NOT FEAR · 2026-11-20 · 3분 읽기

같은 행사를 홈페이지에 적고, SNS 문장을 다시 쓰고, 주보에 옮기다 보면 작은 차이가 생깁니다. 신청 마감이나 장소가 바뀌면 어느 안내를 고쳐야 하는지도 헷갈립니다. 여러 번 잘 쓰는 것보다 먼저, 무엇이 기준 정보인지 하나로 정하는 일이 필요합니다.

1. 행사 원문을 먼저 확정합니다

행사명, 대상, 일정, 장소, 신청 방법과 마감, 문의 경로를 한 문서에 모읍니다. 없는 정보는 빈칸 대신 “확인 필요”로 표시하고 게시 전 담당자가 채웁니다. 변경을 승인하는 사람과 원문의 최종 수정일을 정합니다. 교인 명단이나 내부 연락처는 공개용 원문과 분리합니다.

2. 채널별 역할을 나눕니다

홈페이지에는 전체 안내와 변경 사항을 둡니다. SNS에는 핵심 소식과 원문 링크를, 주보에는 필요한 요약과 자세한 안내 경로를 넣습니다. SNS 이미지를 볼 수 없어도 일정과 신청 방법을 알 수 있도록 본문에 중요한 내용을 적습니다. 모든 채널에 같은 긴 글을 붙이는 것과 같은 사실을 일관되게 전하는 것은 다른 일입니다.

3. AI에는 표현의 변환을 맡깁니다

요청 예시: “다음 확정 원문으로 홈페이지 안내, SNS 소개, 주보 요약을 각각 작성해줘. 날짜·장소·대상·마감·문의는 원문과 같게 유지해줘. 없는 혜택이나 초청 인사는 만들지 말고, 빠진 정보는 확인 필요로 표시해줘.” 이는 초안을 만드는 예시이며 사실 확인을 대신하지 않습니다.

검토자는 표현보다 바뀌면 안 되는 항목부터 대조합니다. 날짜와 요일의 일치 여부도 확인합니다. “이번 주”, “내일”처럼 시간이 지나면 뜻이 달라지는 표현은 실제 날짜로 바꾸는 편이 재공유 때의 혼란을 줄입니다.

4. 게시한 위치를 기록합니다

홈페이지 URL, SNS 게시물 URL, 주보 발행일을 기록해두면 일정 변경 시 함께 고칠 수 있습니다. 변경할 때에는 원문을 먼저 수정하고 다른 채널에 반영한 뒤 완료 표시를 합니다. 이미지 안에 들어간 날짜도 별도로 확인합니다. 종료된 행사 안내는 종료 상태를 알아볼 수 있게 정리합니다.

첨부한 양식에는 원문 입력란, AI 요청문, 게시 전 대조 항목과 변경 기록란을 모았습니다. 먼저 규모가 작은 공개 행사 하나에 적용해보세요. 목적은 게시물을 더 많이 만드는 것이 아니라, 같은 안내를 여러 번 정정하는 수고를 줄이고 방문자가 믿을 수 있는 정보를 제공하는 데 있습니다.
