# 함께 거닐다

GitHub Pages용 정적 3D 정원. `/walk/`를 열면 실행됩니다. 별도 빌드·CDN·서버 API가 필요하지 않습니다.

- Three.js 0.170.0은 `vendor/`에 포함하고 MIT 라이선스를 동봉했습니다.
- 양·정원·예배당은 코드로 만든 자체 모델입니다. 외부 캐릭터 자료는 사용하지 않습니다.
- 클릭 및 WASD 이동, 장애물 우회 경로, 카메라 회전/확대, 모바일 터치, 기도/휴식/인사 동작을 지원합니다.
- 기도노트는 localStorage에 최대 100개 저장합니다. 공유·로그인·실시간 다중접속 기능은 없습니다.
- 소리는 사용자 선택 시 Web Audio로 합성한 바람 같은 환경음입니다.

미리보기: 저장소 루트에서 `python3 -m http.server 8765`, 이후 `http://localhost:8765/walk/`.

## 넓은 자연 공간

- 이동 반경을 19에서 68로 확장하고 해안선 안쪽으로 이동을 제한합니다.
- 하늘 그라데이션, 먼 산, 바다 셰이더, 구름, 해안 물결을 추가했습니다.
- 바다 멍 쉼터, 바람의 들판, 숲속 쉼터를 산책로로 연결했습니다.
- 바다 멍 쉼터에 도착하면 메뉴가 사라지는 감상 모드가 열립니다. 화면 탭, Esc, 돌아가기 버튼으로 나옵니다.
- 동작 줄이기 설정에서는 구름과 파도의 움직임을 멈춥니다.
