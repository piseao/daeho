# SO DO NOT FEAR · 브랜드 재정렬

## 핵심 정체성

> SO DO NOT FEAR는 기독교 공동체와 선교 현장을 AI·IT 기술로 돕는 선교단체입니다.

예배와 복음은 사역의 출발점이며, AI·IT는 교회와 선교단체가 복음 사역을 지속하도록 돕는 도구입니다.

## 홈페이지 목표

첫 방문자가 10초 안에 다음 세 가지를 이해하도록 합니다.

1. 누구인가: 기독교 선교단체
2. 무엇을 하는가: AI·IT로 교회와 선교 현장을 지원
3. 어떻게 시작하는가: 교육, 제작, 맞춤 지원 중 선택

## 우선 대상

- 기술 인력과 예산이 부족한 교회
- 홈페이지와 콘텐츠 운영이 필요한 선교단체
- AI를 사역에 안전하게 활용하고 싶은 담당자

## 서비스 구조

- AI·IT 선교 지원: 홈페이지, 번역·자막, 문서와 반복 업무
- 홈페이지 제작: 기획·디자인·개발·배포·인수인계
- 교육·자료: 무료 강의, GitHub 문서, 템플릿과 점검표
- 맞춤 지원: 진단, 원격 세팅, 운영자 교육

## 화면 방향

- Apple식 뉴트럴 모노톤: 블랙·딥 그레이·화이트·라이트 그레이
- 큰 제목, 넓은 여백, 짧고 명확한 문장
- 장식보다 실제 문제와 해결 결과를 우선
- 사진은 낮은 채도 또는 흑백을 기본으로 하되 현장의 온기를 유지
