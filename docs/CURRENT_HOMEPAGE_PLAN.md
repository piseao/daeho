# 현재 홈페이지 제작 기준

사용자가 승인한 최신 요구사항이 이전 기획 문서보다 우선한다.

- 정체성: 기독교 공동체와 선교 현장을 AI·IT로 돕는 선교단체.
- 화이트 중심의 이미지형 매거진, 오렌지 포인트, 작은 로고.
- 메뉴: 소개 / 칼럼 / 프로젝트 / 문의. 로고는 홈, 검색은 별도 아이콘.
- 홈: 대표 콘텐츠, 추천 콘텐츠, 최신 글. 프로젝트는 메뉴에서 접근한다.
- 예배팀 중심 메시지, 쉼·성경 탐험은 메인에서 제외한다.
- 실재하는 콘텐츠 수에 맞춰 구성한다. 빈 카드나 허구 사례를 만들지 않는다.
- 검색·분류·태그와 상세 화면까지 같은 구조로 연결해야 한다.
- 코드 삭제 전 목록 제시. 로컬 검토 후 사용자 확인을 받아 배포한다.

## 확인된 불일치

- BRAND-REPOSITIONING.md의 모노톤은 이전 방향이다.
- AI_IT_MISSION_PLAN.md의 예배팀 운영 항목은 현재 홈페이지 정체성 기준이 아니다.
- 홈과 상세는 magazine-home.mjs의 공통 헤더·푸터와 magazine.css를 공유한다. 관리자와 로컬은 buildFiles를 사용한다.
- 기존 HTML의 칼럼 10편을 JSON으로 복원했다. 추천 카드의 그래픽은 사진 선정 전 임시 상태다.
- file://로 열면 루트 기준 CSS와 이미지가 로드되지 않는다. 반드시 HTTP 서버로 확인한다.

## 로컬 검증

- 390px: 홈, 소개, 칼럼, 프로젝트, 문의, 대표 글의 가로 넘침 없음.
- 1440px: 프로젝트 가로 넘침 없음, 화면 캡처 확인.
- 모바일 메뉴 열기와 칼럼 검색 확인. 아카이브 검색 결과 1건.
- 배포는 사용자 확인 이후 별도 진행.
