# Editorial renewal — 2026-11-13

## Direction
Reference: https://www.living-sense.co.kr/ (viewed in browser). Applied image-led editorial hierarchy, restrained navigation, generous gutters, category cards. No reference photography, articles, logos or code copied. Existing brand assets and actual screenshots of our own experiences are used.

Existing Notion/Padlet/YouTube/contact paths remain reachable. No newsletter signup or testimonial is fabricated.

## Architecture
- `content/editorial.json`: public content source.
- `editorial/render.mjs`: deterministic, escaped HTML renderer shared by browser editor and local build.
- `tools/build-editorial.mjs`: regenerate home, archive, articles, four informational pages, sitemap.
- `admin/`: form-based editor, local drafts, JSON backup/import, WebP upload conversion, sandboxed preview, GitHub publishing.
- `admin/publisher.mjs`: GitHub Git database transaction. Checks exact starting branch head; uploads blobs; creates a tree on the current tree; creates one commit; updates main with `force:false`. Concurrent updates fail closed.

Hosting remains GitHub Pages, existing main/root source, no paid backend or database. Static HTML is generated by the editor and committed with content, so articles and metadata do not depend on client fetching for search indexing.

## Operator authentication
Editor URL is public. GitHub enforces write access; there is no fake client-side password. Operator connects a fine-grained token limited to this repository, Contents read/write. Token is only held in closure memory, never localStorage, backup, URL or repository. Each new session must reconnect. OAuth/account-password login would require a separate trusted authentication service and is not claimed here.

`published:false` is a visibility flag, not private storage. Published JSON and Git history are public. Unpublished confidential drafts must not be published to this repository. UI and guide state this distinction.

- Mobile emulation: 390 × 844. Fixed grid intrinsic-width overflow in editor; verified scrollWidth/clientWidth 390/390 with fresh CSS. Not a physical phone test.
- Internal page, asset and fragment links scanned, no broken targets.
- Existing journey regression: 11 worlds, 33 stories, 60 routes. No files inside `/walk/` or `/journey/` modified.
- Real API publication and Pages status are recorded in the task completion report after release.

## Operation
See `/admin/guide.html` for operator setup and workflows. Keep original photos and backups. A failed publication does not advance the branch; unreachable uploaded blobs are not live site content. Network failure after final update may be ambiguous; reload remote state before retrying. The editor refuses to force overwrite.
