# 교회·선교단체 무료 홈페이지 만들기 YouTube 강의 기획안

## 1. 강의의 한 문장

> 코딩을 몰라도 작은 교회와 선교단체가 GitHub Pages와 무료 도구를 활용해 직접 공식 홈페이지를 만들고 운영하도록 돕는 실습 강의.

So Do Not Fear 홈페이지를 실제 사례로 사용한다. 완성 화면만 보여주는 강의가 아니라 기획, 콘텐츠 준비, 제작, 배포, 검색 등록과 안전한 운영까지 전 과정을 공개한다.

이 강의는 홈페이지 하나를 만드는 데서 끝나지 않는다. 더 많은 그리스도인이 AI와 바이브 코딩으로 복음을 위해 필요한 것을 직접 만들고, 자신의 경험을 다른 교회와 선교 현장에 다시 나누는 창작자와 동역자로 세워지도록 돕는다.

## 2. 핵심 홍보 문구

메인 질문:

> 공짜 홈페이지? 작은 교회도 직접 만들 수 있습니다.

이어지는 설명:

> GitHub Pages를 사용하면 서버 비용 없이 공식 홈페이지를 시작할 수 있습니다. 맞춤 도메인과 일부 외부 서비스에는 선택 비용이 생길 수 있지만, 홈페이지의 기본 제작과 배포는 무료로 시작할 수 있습니다.

`평생 완전 무료`, `비용이 절대 들지 않는다`, `5분이면 누구나 완성`처럼 조건을 숨기거나 과장하는 표현은 사용하지 않는다.

## 3. 시청 대상

- 홈페이지 제작비가 부담되는 개척교회와 작은 교회
- 홈페이지 담당자가 따로 없는 선교단체와 예배팀
- 기존 홈페이지가 오래되어 직접 새로 만들고 싶은 사역자
- 코딩 경험은 없지만 문서 편집과 계정 관리는 할 수 있는 봉사자
- 담당자가 바뀌어도 유지할 수 있는 단순한 홈페이지가 필요한 공동체

## 4. 수강 후 완성할 결과

수강자는 다음 내용을 갖춘 정적 홈페이지를 완성한다.

- 공동체 소개와 핵심 신앙고백
- 예배·모임 시간과 장소
- YouTube 설교 또는 예배 영상
- 공지사항과 사역 소식
- Google Forms 문의
- Padlet 기도제목, Google 포토와 Notion 등 외부 채널 연결
- 모바일 대응, 검색 메타 정보와 HTTPS
- 안전한 수정·배포·인수인계 문서

회원가입, 교인 명부, 비공개 상담, 결제 처리와 관리자 게시판은 이 무료 정적 홈페이지 강의의 범위에서 제외한다.

## 5. 무료 학습과 유료 지원의 연결 구조

```text
YouTube 본 강의·Shorts 또는 Instagram 콘텐츠
→ 무료 영상 시청
→ GitHub 예제와 제작 매뉴얼로 직접 실습
→ 카카오톡 모임 또는 공개 Issue에서 기본 질문
→ 개인 도움이 필요한 경우 Google Forms로 요청
→ 범위·일정·비용 사전 안내
→ 1:1 대면 또는 원격 유료 강의
→ 수강자가 직접 운영할 수 있도록 인수인계
```

무료 자료만으로 끝까지 만들 수 있는 경로를 유지한다. 유료 안내는 시청자가 먼저 개인 지원을 요청했을 때 제공하며, 홈페이지 자체의 가격이 아니라 맞춤 진단·강의·원격 지원 시간에 대한 비용임을 분명히 설명한다.

### 유료 지원 유형

| 유형 | 적합한 요청 | 제공 결과 |
| --- | --- | --- |
| 1:1 기초 강의 | GitHub와 파일 수정이 처음인 담당자 | 자신의 컴퓨터에서 수정·배포하는 방법 습득 |
| 원격 문제 해결 | 배포, 도메인, 링크 또는 화면 오류 | 원인 설명, 함께 수정, 재발 방지 기록 |
| 제작 동행 | 기획부터 공개까지 함께 진행해야 하는 공동체 | 단계별 실습, 배포 확인, 운영자 인수인계 |

구체적인 금액은 준비 시간, 강의 시간, 도메인 작업과 콘텐츠 정리 범위를 확인한 뒤 사전에 안내한다. 작업을 시작하기 전에 포함 항목, 제외 항목, 일정, 비용, 취소·환불 기준을 문서로 합의한다.

### 개인 강의 요청 폼 권장 항목

- 교회·선교단체·예배팀 이름
- 담당자 이름과 답변받을 연락처
- 홈페이지가 현재 있는지 여부와 공개 주소
- 원하는 도움: 기초 강의 / 문제 해결 / 제작 동행
- 대면 또는 원격 방식
- 가능한 일정
- 현재 가장 어려운 점
- 개인정보 수집·이용 동의

비밀번호, 2단계 인증 코드, API 키와 관리자 로그인 정보는 폼에서 받지 않는다. 원격 지원 중에도 운영자가 직접 로그인하며 화면 녹화와 계정 접근 범위를 사전에 합의한다.

## 6. 본 강의 시리즈

각 영상은 10~18분을 기준으로 하고, 시청자가 한 편마다 하나의 결과를 완성하게 한다.

### 0강. 공짜 홈페이지, 정말 가능할까?

- 제목 예시: `교회 홈페이지 제작비 0원? 가능한 것과 불가능한 것`
- GitHub Pages가 무료인 이유
- 무료인 항목과 선택 비용이 드는 항목 구분
- 정적 홈페이지에 적합한 교회와 적합하지 않은 경우
- 완성 사례로 So Do Not Fear 홈페이지 소개
- 과제: 우리 공동체에 필요한 기능과 필요하지 않은 기능 나누기

### 1강. 코딩보다 먼저 준비할 한 장

- 공동체 이름과 한 문장 소개
- 홈페이지의 대상과 목적
- 신앙고백과 사역 방향
- 예배 시간, 장소와 연락 방법
- 공개 가능한 사진·영상 확인
- 운영 책임자와 보조 담당자 지정
- 과제: 홈페이지 기획 한 장 작성

### 2강. GitHub 계정과 홈페이지 저장소 만들기

- GitHub 계정 생성과 2단계 인증
- 저장소, 파일, commit과 Pages를 쉬운 언어로 설명
- 예제 저장소 Fork 또는 템플릿 복사
- 라이선스와 복제 가능한 범위 확인
- 과제: 자신의 공동체 이름으로 저장소 준비

### 3강. 우리 교회 내용으로 바꾸기

- `index.html`에서 이름, 소개와 예배 정보 수정
- `content/site-data.json`에서 공지와 이야기 수정
- 대표 이미지 교체와 공개 동의 확인
- 확정되지 않은 정보를 임의로 만들지 않는 원칙
- 과제: 소개·예배·공지 콘텐츠 교체

### 4강. 디자인과 모바일 화면 정리하기

- `styles.css`의 색상과 글자 크기 바꾸기
- 교회 로고와 대표 색상 적용
- 모바일에서 메뉴와 문장이 겹치지 않는지 확인
- 디자인보다 정보 전달을 우선하는 기준
- 과제: 휴대전화와 컴퓨터 화면 모두 점검

### 5강. 무료 도구 연결하기

- YouTube 영상 삽입
- Google Forms 문의 연결
- Padlet 기도제목 연결
- Google 포토 앨범과 Notion 칼럼 연결
- 관리자 링크와 방문자 링크를 구분하는 방법
- 과제: 외부 채널 두 개 이상 연결

### 6강. GitHub Pages로 무료 배포하기

- `main` 브랜치와 GitHub Pages 설정
- commit과 push로 변경 내용 배포
- 배포 성공 여부와 실제 사이트 확인
- 기본 `github.io` 주소로 무료 운영하기
- 과제: 첫 공개 주소 만들기

### 7강. 도메인과 검색 등록하기

- 맞춤 도메인은 선택 유료 항목임을 설명
- `CNAME`, DNS와 HTTPS의 기본 개념
- Google Search Console과 네이버 서치어드바이저
- 제목, 설명, 공유 이미지와 사이트맵 점검
- 과제: 기본 주소 유지 또는 맞춤 도메인 연결 결정

### 8강. 안전하게 오래 운영하기

- 공개 저장소에 넣으면 안 되는 비밀번호와 개인정보
- 사진, 아동 이미지와 저작권 동의
- 비공개 기도제목과 상담을 홈페이지에 저장하지 않는 이유
- 계정 복구, 담당자 교체와 운영 문서
- 매월 점검표와 백업 방법
- 과제: 두 번째 운영자와 인수인계 문서 정하기

### 9강. 처음부터 배포까지 실제 사례 총정리

- So Do Not Fear 홈페이지의 기획부터 배포까지 복습
- 실제로 어려웠던 부분과 해결 과정
- 처음 시작하는 공동체가 자주 하는 실수
- 저장소, 전체 제작 매뉴얼과 도움 요청 방법 안내
- 최종 과제: 자신의 홈페이지 주소와 운영 계획 완성

## 7. 영상 한 편의 공통 구성

```text
00:00  오늘 해결할 문제와 완성 화면
00:20  이번 영상에서 만들 결과
00:50  꼭 알아야 할 개념 한 가지
02:00  실제 화면 실습
10:00  자주 생기는 오류와 해결법
12:00  보안·개인정보·저작권 확인
13:00  오늘의 과제와 다음 강의 예고
```

화면 녹화에서는 비밀번호, 이메일 수신함, 복구 코드, API 키, 관리자 전용 URL과 실제 개인정보가 보이지 않도록 별도 시연 계정을 사용하거나 편집으로 가린다.

## 8. 1강 오프닝 대본 예시

> 교회 홈페이지를 만들려고 견적을 알아보다가 비용 때문에 포기하신 적이 있으신가요? 서버 비용 없이 시작할 수 있는 방법이 있습니다. 바로 GitHub Pages를 이용하는 것입니다. 이 강의에서는 실제 예배팀 홈페이지를 함께 만들면서 소개, 예배 안내, 설교 영상, 공지와 문의까지 연결해 보겠습니다. 코딩을 외우는 강의가 아닙니다. 준비된 파일에서 우리 공동체의 내용과 사진을 바꾸고, 안전하게 공개하고, 다음 담당자도 이어서 관리할 수 있게 만드는 강의입니다. 다만 맞춤 도메인처럼 선택적으로 비용이 드는 부분은 정확히 구분해서 알려드리겠습니다.

## 10. 바로 촬영할 수 있는 Shorts 대본

### Shorts 1. 교회 홈페이지, 정말 공짜일까?

> 교회 홈페이지, 정말 공짜로 만들 수 있을까요? GitHub Pages를 이용하면 서버 비용 없이 홈페이지를 공개할 수 있습니다. 기본 `github.io` 주소도 무료입니다. 다만 우리 교회만의 맞춤 도메인을 사용하면 도메인 구입비는 별도로 필요합니다. 무료인 것과 유료인 것을 정확히 구분해서, 작은 교회도 직접 운영하는 방법을 알려드리겠습니다.

화면 문구: `서버·배포 0원 / 맞춤 도메인은 선택 비용`

### Shorts 2. 홈페이지보다 먼저 만들 한 장

> 홈페이지를 만들기 전에 코딩부터 시작하지 마세요. 공동체 이름, 한 문장 소개, 예배 시간과 장소, 연락 방법, 공개할 사진, 운영 담당자. 이 여섯 가지를 먼저 한 장에 적으면 홈페이지 제작이 훨씬 쉬워집니다. 확정되지 않은 정보는 지어내지 말고, 확정 후 안내라고 표시하세요.

화면 문구: `코딩 전에 홈페이지 기획 한 장`

### Shorts 3. 문의 폼 링크의 함정

> Google Forms를 홈페이지에 연결할 때 편집 주소를 복사하면 안 됩니다. 반드시 게시된 응답자 링크를 복사하세요. 그리고 폼에는 비밀번호, 주민등록번호, 금융정보 같은 민감한 정보를 받지 마세요. 홈페이지는 연결 통로이지, 모든 개인정보를 저장하는 곳이 아닙니다.

화면 문구: `편집 링크 ✕ / 응답자 링크 ○`

## 11. 제목과 썸네일 문구

시리즈 제목 후보:

- `작은 교회 홈페이지, 무료로 직접 만들기`
- `제작비 없이 시작하는 교회 홈페이지`
- `코딩 몰라도 만드는 교회·선교단체 홈페이지`

썸네일 문구 후보:

- `교회 홈페이지 0원?`
- `서버비 없이 시작`
- `작은 교회도 직접!`
- `코딩 몰라도 됩니다`
- `문의·영상·공지 한 번에`

검색 제목에서는 `무료`만 반복하지 말고 `교회 홈페이지`, `선교단체 홈페이지`, `GitHub Pages`, `직접 만들기`처럼 시청자가 실제로 찾는 주제를 자연스럽게 사용한다.

## 12. 설명란 공통 문안

```text
작은 교회·개척교회·선교단체가 GitHub Pages를 이용해 직접 홈페이지를 만들고 운영하는 과정을 나눕니다.

예제 홈페이지: https://sodonotfear.com/
예제 저장소: https://github.com/piseao/daeho
전체 제작 매뉴얼: 저장소의 docs/HOMEPAGE_BUILD_MANUAL.md
질문과 오류 제보: 저장소의 GitHub Issues
개인 강의 요청: 홈페이지의 문의하기

GitHub Pages와 기본 github.io 주소는 무료로 사용할 수 있습니다. 맞춤 도메인, 일부 외부 서비스와 전문 유지보수에는 별도 비용이 발생할 수 있습니다. 공개 저장소에 비밀번호, API 키, 개인정보와 비공개 기도제목을 올리지 마세요.
```

## 13. 채널별 운영 역할

| 채널 | 주된 역할 | 다음 행동 |
| --- | --- | --- |
| 홈페이지 | 예배팀 정체성과 공식 정보 | 예배·기도·강의 문의 |
| YouTube | 예배·말씀과 전체 제작 강의 | 구독, 본 강의 시청, 실습 |
| Shorts | 짧은 문제 해결과 신규 시청자 유입 | 관련 본 강의 이동 |
| Instagram | 예배팀의 과정과 강의 소식 | 홈페이지·YouTube 이동 |
| 카카오톡 모임 | 공지, 교제와 지속적인 관계 | 예배 참여, 공개 학습 질문 |
| GitHub | 코드, 매뉴얼과 해결 기록 | 직접 제작, Issue 질문 |
| Google Forms | 일반 문의와 개인 강의 요청 | 상담 범위와 일정 확인 |

카카오톡 모임에서는 공개해도 되는 제작 질문과 공지를 중심으로 운영한다. 목회 상담, 비공개 기도제목, 계정 정보와 결제 정보가 단체방에 남지 않도록 운영 원칙과 관리자를 정한다.

## 15. 제작 준비물

- 시연용 GitHub와 Google 계정
- 개인정보가 없는 예제 교회 데이터
- 데스크톱 화면 녹화와 모바일 확인 화면
- 완성 전후 비교 이미지
- 강의별 체크리스트 PDF 또는 Markdown
- 영상 설명란에 넣을 저장소와 매뉴얼 링크
- 비밀번호와 관리자 링크를 가리는 편집 프리셋

## 16. 성과 확인 기준

조회수만 보지 않고 실제로 다른 공동체가 홈페이지를 완성하고 유지할 수 있는지를 확인한다.

- 본 강의의 평균 시청 지속 시간
- Shorts에서 본 강의로 이동한 비율
- 매뉴얼 열람과 저장소 Fork 수
- 실제 홈페이지 완성 사례 수
- 반복해서 들어오는 질문과 오류 유형
- 개인정보·보안 사고 없이 운영된 사례

반복 질문은 다음 영상과 제작 매뉴얼에 반영하여 강의와 문서를 함께 개선한다.
