Getting Started

01. 우리 공동체의 내용을 준비합니다. 소개·예배 시간·연락 방법을 한 문서에 모으고, 사용할 사진과 영상의 공개 가능 여부를 확인합니다.

02. 예제를 복사하고 내용을 바꿉니다. GitHub 예제를 자신의 계정으로 복사합니다. 제작 매뉴얼을 따라 이름·사진·안내 문구를 바꾸고, 필요하면 AI에 수정을 요청합니다. AI가 만든 내용은 담당자가 확인합니다.

03. 홈페이지를 공개합니다. GitHub Pages를 설정하고 기본 주소에서 화면과 링크를 확인합니다. 맞춤 도메인은 선택 사항입니다.

04. 공지 수정과 운영을 연습합니다. 공지와 예배 정보를 수정한 뒤 실제 사이트에 반영됐는지 확인합니다. 다음 담당자도 이어갈 수 있도록 계정과 수정 방법을 기록합니다.

무료인 것과 비용이 드는 것

무료로 시작

공개 예제 코드와 제작 매뉴얼, GitHub Pages의 기본 홈페이지 배포와 github.io 주소를 사용합니다.

필요에 따라 선택

맞춤 도메인, 유료 AI 도구·외부 서비스, 1:1 강의와 원격 세팅에는 비용이 발생할 수 있습니다. 개인 지원은 범위와 비용을 먼저 안내합니다.

자주 묻는 질문

바이브 코딩으로 어떻게 선교를 돕나요?

그리스도인이 AI와 자연어를 활용해 홈페이지와 디지털 도구를 만들도록 가르치고, 교회와 선교단체가 직접 운영할 수 있도록 강의와 세팅으로 돕습니다.

무료 교회 홈페이지를 만들 수 있나요?

GitHub Pages와 기본 github.io 주소를 사용하면 서버 비용 없이 무료 교회 홈페이지를 시작할 수 있습니다. 맞춤 도메인, 일부 외부 서비스와 개인 강의에는 비용이 발생할 수 있습니다.

무료 홈페이지 제작 강의는 어떻게 보면 되나요?

영상 강의는 준비 중입니다. 지금은 시작 안내와 공개 제작 매뉴얼, 예제 코드를 이용할 수 있습니다.

개인 강의나 원격 세팅을 요청할 수 있나요?

공개 제작 문서를 먼저 이용할 수 있습니다. 개인 도움이 필요한 경우 문의 폼으로 요청하면 범위와 비용을 사전 협의한 뒤 1:1 또는 원격 유료 강의를 안내합니다.

막히는 부분은 함께 살펴봅니다.

현재 상황과 배우고 싶은 내용을 알려주세요. 기초 강의, 원격 문제 해결, 제작 동행 중 필요한 도움을 안내합니다.
