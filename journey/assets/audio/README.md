# Original Journey score

Five original 32-second synthesized compositions: village, alley, field, wonder, birth.
Created for this repository by `journey/scripts/render-score.py` (standard-library Python).
No external recordings, samples, existing melodies, paid services, or third-party asset licenses.
These are modern ambient interpretations, not reconstructions of ancient music.
Distribution: 16 kHz, mono, 16-bit PCM WAV, approximately 1.02 MB each (5.12 MB total).
Only the current zone downloads on demand; decoded cache retains at most three tracks.
Two-second zone crossfades. Each miniature has a quiet loop boundary, not a continuous orchestral recording.
Repository content terms apply; no third-party attribution requirement introduced.
Narration recordings are not included. Captions remain the primary story delivery.
