# 베들레헴 1차 환경 개선 검수

범위: 지형, 건축, 골목, 조명, 환경 애니메이션. 기존 NPC·탄생/들판 시네마틱·성경 이야기·묵상 기능은 유지한다. 새 NPC 상태 머신, 고품질 주요 인물, 음성 내레이션은 이 단계의 완료 항목이 아니다.

## 구조 및 공간 설계

- 기존 Three.js와 양 컨트롤러를 재사용한다. `village.js`가 베들레헴에서만 로딩되고, 환경 전용 `environment.js`를 불러온다. 라이브러리·서버·API 추가 없음.
- 주거 가옥 8채에서 **20채**로 확장. 서쪽 주거 골목과 작업 공간, 시장의 천막 3개, 북쪽 주거 능선, 동쪽 들판·전망대, 입구 바깥 접근로를 구분했다. 배경의 먼 마을은 별도 실루엣이다.
- 도로를 연속 곡선으로 재구성하고 건물 기단에 지형을 맞춘다. 낮은 돌담, 전망대의 얕은 돌 디딤판, 벤치, 석재 화덕, 장작, 작업대와 생활 소품을 배치했다.
- 석재 표면은 직접 생성한 256px 텍스처를 공유한다. 열린 목재 문, 창살과 발광 창, 석재 모서리, 돌출 목재 보, 높이가 다른 평지붕을 구성했다.
- 둥근 먼 언덕, 넓은 외곽 지면, 밤하늘 그라데이션·별·달, 안개로 깊이를 보강했다. 올리브나무는 갈라지는 가지와 부드러운 수관으로 수정했다.
- 천막의 처짐과 바람, 풀의 셰이더 움직임, 기존 등불·불·나무의 환경 애니메이션을 함께 사용한다. 동작 줄이기 설정에서는 바람 애니메이션을 고정한다.

## 비용 관리

- 기존 실제 조명 수를 유지. 추가 창빛과 바닥의 부드러운 빛은 공유 마스크 인스턴싱으로 처리한다. 후처리 블룸은 사용하지 않는다.
- 정적 부품은 공통 geometry/material로 묶고 정적 배치에 경계구와 프러스텀 컬링을 사용한다. 동적 배치는 변형 때문에 컬링을 보수적으로 유지한다.
- 풀: PC 380개, 모바일 180개. 지형·별·양·그림자의 기존 모바일 축소 설정 유지.
- 천막은 카메라에서 먼 경우 갱신하지 않으며 모바일 15Hz / PC 24Hz로 변형한다. 텍스처·geometry·material·instance buffer는 세계 전환 시 해제한다.

## 로컬 Chrome 검증 (2026-11-04)

동일 Mac Chrome에서 실제 렌더링했으며 모바일은 **390×844, DPR 2 에뮬레이션**이다. 실물 Android/iOS 및 저사양 GPU 검증은 수행하지 않았다. 각 성능 표본은 로딩 안정화 후 초기 탐험 시점의 5초 rAF 간격 측정이다. draw calls/triangles는 해당 프레임의 Three.js renderer.info 값이며 카메라와 그림자 패스에 따라 달라진다.

| 환경 | 개선 전 FPS | 최종 FPS | 최종 p95 프레임 간격 | draw calls | triangles |
|---|---:|---:|---:|---:|---:|
| PC 1440×900 | 60 | 60 | 16.7ms | 156 | 75,550 |
| 모바일 에뮬레이션 | 60 | 60 | 16.8ms | 141 | 58,450 |

- 20개 가옥 내부와 기존 발견 지점 5개의 경로 탐색 모두 성공.
- 실제 마우스 클릭으로 (7,10.7) 입구 앞까지 이동, 다시 클릭하여 (7.06,7.40) 집 안 도착. 지붕이 열리고 양이 보이는 화면 확인.
- 집 안에서 W 키를 3초 눌러도 뒤쪽·옆쪽 벽에서 정지: (8.75,5.45). 벽을 관통하지 않음.
- 모바일 touchStart/touchEnd 입력 후 양의 실제 위치 변화 확인. 시장/골목으로 이동한 뒤 기존 설명이 열림.
- 나머지 10개 세계를 순서대로 전환하여 이름·기존 이야기 3개·베들레헴 UI 제거 확인.
- 베들레헴 ↔ 나사렛 3회 왕복 후 geometry 74개 / texture 3개로 동일. 무한정 늘어나는 GPU 자원 현상은 이 표본에서 관찰되지 않음.
- 애플리케이션 JavaScript 예외 없이 검증 완료. `git diff --check` 통과. `/walk/`, `worlds.js`, 다른 세계의 배경 생성 코드는 변경하지 않음.

## 자료와 품질 판정

건축은 예술적 재구성이다. [Nazareth Village의 평지붕 연구](https://nazarethvillage.com/about/research-and-archaeology/the-houses/roofs/)와 [테라스 복원](https://nazarethvillage.com/about/research-and-archaeology/terrace-restoration/terraces/), [이스라엘 외교부의 제2성전기 예루살렘 주택 설명](https://www.gov.il/en/pages/jerusalem-the-upper-city-during-the-second-temple-period)을 지역 건축의 참고로 사용했다. 갈릴리·예루살렘 자료를 베들레헴의 특정 건물 복원으로 주장하지 않는다. 자료의 이미지나 모델을 가져오지 않았으며, 외부 자산 라이선스를 추정하여 사용한 사례도 없다.

이번 결과는 **환경의 1차 개선본**이다. 애니메이션 영화 수준의 최종 완성 또는 10–15분 콘텐츠 완성을 주장하지 않는다. 기존 마리아·요셉·아기 모델은 절차적 임시 모델로 남아 있다. 2차 이상은 사용자 확인 후 진행한다.

다음 검토 항목: 실제 저사양 기기에서 발열·지속 FPS 확인, 장면별 마을 가림을 줄이는 카메라 조정, 중요 장소의 더 정교한 자산 제작. 향후 주요 인물은 라이선스가 확인된 독창적인 GLB/glTF 리깅 모델과 호흡·시선·손동작 클립이 필요하다. 이번에는 해당 모델을 새로 연결하거나 제작 완료로 보고하지 않는다.
