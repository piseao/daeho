# 함께 거닐다 — 예수님의 발자취

`/journey/`는 기존 `/walk/`와 별도의 3D 성경 이야기 공간입니다.

- 11개 세계, 세계별 성경 요약 3개(총 33개), 본문 출처와 묵상 질문.
- 여정 지도, 이전·다음 이동, `#bethlehem` 등의 직접 링크.
- 작은 양의 클릭/키보드 이동, 장애물 우회, 모바일 회전·확대.
- 읽은 이야기와 세계별 묵상 기록은 이 브라우저의 localStorage에 저장됩니다.
- 혼자 체험하는 공간입니다. 실시간 접속자 표시나 글 공유 기능은 없습니다.
- Three.js는 기존 `../walk/vendor/three.module.js`를 공유합니다. 라이선스는 해당 폴더의 `THREE-LICENSE.txt`를 참조합니다.
- 다른 세계로 이동할 때 이전 세계의 3D 자료를 해제합니다.

텍스트는 성경을 바탕으로 직접 작성한 요약이며 특정 성경 번역본을 인용하지 않습니다. 건물·인물·배치는 본문 이해를 돕는 예술적 재구성으로, 역사·고고학적 복원 자료가 아닙니다. 2번째 나사렛 세계의 성전 이야기는 예루살렘 방문에 관한 기록입니다.

로컬 확인: 저장소 루트에서 `python3 -m http.server 8765` 후 `/journey/`를 엽니다.

## WORLD 01 · 살아 있는 베들레헴

베들레헴에서만 `bethlehem/village.js`를 동적으로 불러옵니다. 다른 세계의 데이터와 배경은 유지합니다.

- 높낮이가 있는 지형, 여덟 채의 출입 가능한 가옥, 연결 골목, 천막·항아리·바구니·돌담, 먼 산과 마을을 구성했습니다. 집 안으로 들어가면 지붕을 숨겨 캐릭터가 보입니다.
- 주민 3명(걷기·짐 운반·앉기), 목자 2명, 마리아·요셉, 양 떼 8마리(모바일 5마리)를 배치했습니다. 이동하는 인물은 장애물과 주변 인물을 확인하며 걷고 멈춥니다.
- 구유·들판 가까이 가면 조명과 카메라 연출이 먼저 시작되고 기존 성경 요약이 이어집니다. 건너뛰기와 Escape를 지원하며 동작 줄이기 설정에서는 카메라를 고정합니다. 세로 화면은 인물이 잘리지 않도록 구도를 넓힙니다.
- 마을 입구·구유·들판·골목·전망대의 다섯 장소를 탐험할 수 있습니다. 추가 발견은 점수나 수집 보상을 제공하지 않습니다.
- 환경음은 선택해서 켜며 브라우저 내부에서 합성합니다. 연출 중에는 음량을 낮춥니다. 외부 리소스나 API는 사용하지 않습니다.
- 반복 부품은 InstancedMesh로 묶고 모바일 지형·별·양·그림자 해상도를 낮춥니다. 세계 이동 시 GPU 자원, 전용 UI, 오디오를 해제합니다.

검증용 `?debug=1`에서는 `window.journeyDebug()`로 위치·경로 도달 여부·렌더링 통계를 읽을 수 있습니다. 이동이나 진행도를 변경하는 기능은 아닙니다.
