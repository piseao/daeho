# 함께 거닐다 — 예수님의 발자취

`/journey/`는 기존 `/walk/`와 별도의 3D 성경 이야기 공간입니다.

- 11개 세계, 세계별 성경 요약 3개(총 33개), 본문 출처와 묵상 질문.
- 여정 지도, 이전·다음 이동, `#bethlehem` 등의 직접 링크.
- 작은 양의 클릭/키보드 이동, 장애물 우회, 모바일 회전·확대.
- 읽은 이야기와 세계별 묵상 기록은 이 브라우저의 localStorage에 저장됩니다.
- 혼자 체험하는 공간입니다. 실시간 접속자 표시나 글 공유 기능은 없습니다.
- Three.js는 기존 `../walk/vendor/three.module.js`를 공유합니다. 라이선스는 해당 폴더의 `THREE-LICENSE.txt`를 참조합니다.
- 다른 세계로 이동할 때 이전 세계의 3D 자료를 해제합니다.

텍스트는 성경을 바탕으로 직접 작성한 요약이며 특정 성경 번역본을 인용하지 않습니다. 건물·인물·배치는 본문 이해를 돕는 예술적 재구성으로, 역사·고고학적 복원 자료가 아닙니다. 2번째 나사렛 세계의 성전 이야기는 예루살렘 방문에 관한 기록입니다.

로컬 확인: 저장소 루트에서 `python3 -m http.server 8765` 후 `/journey/`를 엽니다.
