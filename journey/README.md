# 함께 거닐다 — 예수님의 발자취

`/journey/`는 기존 `/walk/`와 별도의 3D 성경 이야기 공간입니다.

- 11개 세계, 세계별 성경 요약 3개(총 33개), 본문 출처와 묵상 질문.
- 여정 지도, 이전·다음 이동, `#bethlehem` 등의 직접 링크.
- 작은 양의 클릭/키보드 이동, 장애물 우회, 모바일 회전·확대.
- 읽은 이야기와 세계별 묵상 기록은 이 브라우저의 localStorage에 저장됩니다.
- 혼자 체험하는 공간입니다. 실시간 접속자 표시나 글 공유 기능은 없습니다.
- Three.js는 기존 `../walk/vendor/three.module.js`를 공유합니다. 라이선스는 해당 폴더의 `THREE-LICENSE.txt`를 참조합니다.
- 다른 세계로 이동할 때 이전 세계의 3D 자료를 해제합니다.

텍스트는 성경을 바탕으로 직접 작성한 요약이며 특정 성경 번역본을 인용하지 않습니다. 건물·인물·배치는 본문 이해를 돕는 예술적 재구성으로, 역사·고고학적 복원 자료가 아닙니다. 2번째 나사렛 세계의 성전 이야기는 예루살렘 방문에 관한 기록입니다.

로컬 확인: 저장소 루트에서 `python3 -m http.server 8765` 후 `/journey/`를 엽니다.

## 베들레헴 환경 1차 (2026-11-05)

`worlds/bethlehem.js`에서 베들레헴 환경을 독립적으로 생성합니다. 24채의 주택, 시장 골목, 들판·전망대, 지형 높이에 맞는 이동, 환경 바람과 조명을 포함합니다. 나머지 10개 세계는 기존 구조를 사용합니다. 이는 1차 작업 당시 범위입니다. 이후 통합 개선에서 일반 NPC·오디오·공간 시네마틱을 추가했으며 주요 인물 최종 모델은 아직 없습니다.

검증 결과와 품질 한계: [1차 구현 보고서](qa/PHASE1-REPORT.md).
로컬 검토: `python3 -m http.server 8765 --bind 127.0.0.1` → `http://127.0.0.1:8765/journey/`.

## 통합 개선 작업

- `systems/audio.js`: 외부 음원 없이 실제 재생되는 자체 합성 악곡 11개 월드 설정, 위치별 환경음, 개별 볼륨·음소거·저장·ducking. 소리 켜기 상호작용 후 시작합니다.
- `systems/inhabitants.js`: 주민 4명·목자 2명·양 7마리의 경량 시안과 행동·경로·충돌.
- `systems/cinematics.js`: 도착/탄생 공간/목자 들판의 타임라인, 자막과 재생 제어. 실제 음성 및 주요 인물 연기는 미완료입니다.
- 환경: 5종 건축 유형, 20개 생활공간 묶음, 지붕 있는 방 21개. 역사 자료와 예술적 추정을 분리합니다.
