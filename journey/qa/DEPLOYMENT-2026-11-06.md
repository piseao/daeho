# 배포 검증 · 2026-11-06

사용자 요청에 따라 최신 origin/main을 기준으로 journey 개선본을 준비했다. 홈페이지의 다른 변경과 walk 파일은 변경하지 않는다.

- CPU 통합 검사: 48개 경로, 90초 NPC 시뮬레이션 통과.
- 실제 Chromium에서 11개 월드 전환 및 33개 이야기 경로/각 세계의 버튼 3개 확인.
- 데스크톱 120프레임 샘플 약 29.73fps, 229 draw calls. 60fps 달성으로 보고하지 않음.
- 모바일 390×844/DPR2 에뮬레이션: 터치 방향 패드로 위치 변경, 렌더 DPR1.25, 가로 넘침 없음.
- 음악 실제 AudioContext running, 4개 악곡 voice 및 RMS 0.00133 출력 확인.
- 이전 보고서의 브라우저 공간 문제는 새 배포 검증에서 해소했다.
- 주요 인물 최종 모델·실제 음성·실기기 Android/iPhone/Safari 검증은 여전히 미완료.

운영 반영은 GitHub Pages 빌드 성공 및 운영 사이트의 파일·브라우저 로딩을 별도로 확인한다.
