## 근거와 재현 경계

- **발굴 자료**: Yardenna Alexandre (2020), IAA ‘Atiqot 98, [The Settlement History of Nazareth](https://publications.iaa.org.il/atiqot/vol98/iss1/3/). 초기 로마 시대 주거와 지하 저장시설 확인. 이는 갈릴리 자료이며 베들레헴 건물의 직접 발굴 근거가 아니다.
- **실험적 복원**: Nazareth Village [주거](https://nazarethvillage.com/about/research-and-archaeology/the-houses/), [지붕](https://nazarethvillage.com/about/research-and-archaeology/the-houses/roofs/), [재료](https://nazarethvillage.com/about/research-and-archaeology/the-houses/building-materials/). 안뜰 중심 확장, 작은 방, 목재·갈대·흙 지붕을 설계 참고로 사용. 현대의 복원 실험을 발굴 사실과 동일하게 취급하지 않음.
- **유물**: [Milwaukee Public Museum의 등잔 분류](https://www.mpm.org/index.php/research-collections/anthropology/anthropology-collections-research/mediterranean-oil-lamps/lamp-classifications), [IAA 유물 전시를 소개한 Herodian Oil Lamp](https://cojs.org/herodian_oil_lamp/). 작은 둥근 도기와 주둥이·심지를 조형 참고. 전기 가로등 같은 실루엣 제거.
- **성경 기록**: 누가복음 2:1–7의 베들레헴 도착·강보·구유; 2:8–14의 목자·소식·찬양; 2:15–20의 방문. 새로운 대사나 번역문 복사 없이 자체 요약 사용.
- **추정/예술 연출**: 정확한 출생 건물 평면, 마을 지도, 주민 일과, 식생 위치, 하늘빛, 사건의 시간 길이, 음악. 동굴인지 독립 외양간인지 확정하지 않음. 탄생 장소는 여러 가능한 생활공간을 참고한 무대임.
- 복식은 간결한 튜닉·겉옷·두건의 일반적 시각 해석. 특정 인물의 실제 외모·복식 복원 주장이 아님.
- 실제 베들레헴 기후·수종 분포의 전문 검토는 미완료. 현재의 올리브·건조 풀밭은 지역적 일반화이며 특정 탄생 계절을 주장하지 않음.

## 다섯 건축 설계

1. 작은 단실 주택: 낮은 흙 지붕, 비대칭 출입구, 적은 개구부.
2. L자 안뜰 주거: 두 생활동과 열린 마당·저수 시설. 전체를 충돌 상자로 막지 않음.
3. 공방 주거: 생활동 + 기둥 차양·작업대. 주거와 작업 공간의 결합은 복원적 추정.
4. 반매입 저장실: 암반 측벽·낮은 저장동·용기. 초기 로마 주거의 저장시설을 지역간 유추.
5. 가축 마당: 낮은 둘레담·열린 출입구·먹이통·일부 그늘. 정확한 당시 축사 평면의 재현이라고 주장하지 않음.

용도별 부피·평면·지붕·열린 공간·소품을 달리한다. 색상 교체만으로 유형을 세지 않는다.

## 구현 내용

- 20개 생활 공간 묶음, 지붕 있는 방 21개, 구조가 다른 건축 유형 5종. 작은 비대칭 개구부, 흙 지붕·목재 끝단, 열린 마당, 저장 용기, 가축 마당. 건축 군마다 방향을 조금씩 달리하고 충돌·카메라 경계도 같은 변환 적용.
- 기둥형 등불을 작은 도기 등잔 형상으로 수정. 광원이 교체될 때 어두워졌다가 새 위치에서 밝아지게 개선. 목자 장면의 빛은 자막의 해당 구간 이후 등장.
- `systems/audio.js`: 11개 월드의 자체 합성 악곡, 장소에 따른 음역·간격·환경음 변화, 부드러운 음량 전환, 바람·풀 소리·발걸음·양 울음·불소리의 합성. 실제 오디오 샘플 파일은 없지만 Web Audio가 음악과 환경음을 실제 생성·재생한다. 고대 악기 또는 녹음된 현악기·목관 연주가 아니다.
- 음악/환경음/내레이션 볼륨, 배경음악 토글, 전체 음소거, 설정 저장. 명시적인 소리 켜기 후에만 AudioContext 생성·재생. 설정이 저장되어 있어도 새 페이지에서 자동재생하지 않음. 백그라운드에서 정지, 다시 보이면 재개. 월드 변경 시 이전 노트 종료와 페이드.
- 일반 주민 4명·목자 2명·양 7마리. 독립된 상태·위상, 물항아리 운반, 시선 반응, 머무름, 풀 뜯기, 분산된 경로. 건물/다른 배우/플레이어의 충돌 검사. 먼 배우의 미세 동작과 얼굴 디테일 단순화. 주요 인물 최종 모델은 미포함.
- 도착 17초, 탄생 공간 20초, 목자 들판 24초의 데이터 기반 타임라인. 카메라·자막·빛·목자 시선·음악 ducking 연결. 요약/묵상/장면 안내 구분. 다시 보기, 건너뛰기, 말씀 요약 읽기, 탐험 복귀. 자연 종료 때 진행 기록 갱신; 건너뛰기를 완료 처리하지 않음.
- 모바일 방향 패드, 접는 목적지 메뉴, 현재 위치 표시. 느린 프레임이 지속되는 모바일은 렌더 DPR을 1로 낮춤. 지형 격자를 160²에서 100²로 줄임. NPC와 베들레헴 모듈은 해당 월드 진입 시 로딩.
- 실제 재생할 내레이션 파일은 없음. 파일 연결 인터페이스와 ducking/볼륨/미디어 시간 기반 자막 경로는 준비했지만, 제작 음성의 동기화 품질까지 검증했다고 주장하지 않음.

## 발견 후 재수정한 문제

1. 건물 수만 다른 반복 주택 → 구조·용도별 복합 공간으로 변경.
2. 같은 등불 자리에 광원이 순간 이동 → 어두워진 뒤 재배치.
3. NPC를 피하다 멈췄는데 이동 중으로 잘못 판단 → 0 거리의 축 이동을 이동으로 세지 않게 수정하고 1.2초 정체 후 경로 재계산.
4. 목자 장면에서 하늘이 너무 넓고 빛이 희미함 → 카메라 목표를 낮추고 빛 중심/크기/강도 조정. 이 마지막 구도는 브라우저 재확인 대기.
5. 시네마틱 끝에서 카메라가 즉시 복귀 → 약 1.4초의 위치/회전 보간. 움직임 줄이기에서는 즉시 전환. 마지막 보간 변경은 브라우저 재확인 대기.

## 실제 확인한 결과와 남은 검증

### 브라우저에서 확인 완료

Ego Chromium localhost. 운영 사이트도 별도로 로딩 완료, canvas와 이야기 항목 3개 확인. 공개 GitHub 저장소 접근 확인. 운영 배포는 실행하지 않음.

- 소리 켜기 후 AudioContext `running`.
- **음악 단독 검사**: 환경음 0으로 설정, 악곡 oscillator voice 4개, 실제 출력 RMS 약 **0.00110**. 무음의 음악 시스템만 만든 상태가 아님.
- **전체 음소거 검사**: RMS 약 **0.000000437**로 감소.
- 진입 장면과 목자 장면에서 ducking 활성, 닫은 뒤 복귀 확인.
- 시작/다시 보기/건너뛰기/탐험 계속하기 확인.
- 목자 목적지로 이동하는 도중 정체 문제 발견 및 수정 후 도착 확인. 9초 시점 성경 요약 자막 확인. 자연 종료 후 말씀 창 확인.
- 목자 장면 → 구유 이야기 위치로 실제 이동 → 탄생 공간 장면 시작 → 건너뛰기 → 탐험 복귀 확인.
- 해당 시점 NPC 13개 모두 유효한 지형/장애물 위치.
- 베들레헴 이야기 3곳·탐험 목적지 5곳 경로 탐색 성공.
- 페이지 새로고침 시 소리 설정은 보존되나 AudioContext는 `not-started`: 자동재생 제한 준수.

### CPU 통합 회귀 검사

`node journey/qa/regression.mjs`는 실제 환경 생성·NPC·이동 함수·오디오 설정·장면 데이터를 불러온다. 렌더링/FPS 또는 모바일 테스트를 대신하지 않는다.

- 월드 11개, 이야기 33개 유지.
- 출발 지점 6곳 × 목적지 8곳 = **48개 경로**. 0.05 단위로 경로 구간을 검사해 벽 관통 없음.
- **90초, 초당 60회** NPC 시뮬레이션. 건물 진입/지형 높이 불일치/배우 몸 겹침 없음. 13명 중 10명이 0.15 이상 이동. pause/walk/graze/look/sit 상태 관찰. 배우 경계 간 최소 여유 약 0.70.
- 오디오 자동 생성 방지, 볼륨 범위/잘못된 입력/저장 후 복원, 월드 11개 악곡 매핑 확인.
- 장면 자막 타이밍 순서와 범위, 카메라 좌표의 유한값 검사.
- 변경한 모든 JS 구문 검사 통과. 상대 import 파일 모두 존재.
- `/walk/` 전체 파일 SHA-256 일치. `worlds.js` 성경 이야기 파일도 작업 전과 바이트 단위로 동일.

### 아직 확인되지 않은 것

브라우저 작업 공간 7이 사라져 최종 데스크톱 FPS·11월드 전환·모바일 패드/음악 패널/가로 화면 검증이 중단됨. 스킬 규칙에 따라 사용자에게 새 공간 승인을 요청한 상태. 이 통합 버전에 이전 1차 버전의 약30fps 측정값을 재사용하지 않는다.

실제 Android/iPhone 및 Safari, 실제 음성 파일 재생·자막 동기화, 저사양 기기 자동 품질 변경, 최종 카메라 구도·복귀 보간은 미검증이다.

2. 현대 빌라 반복 방지: **개선**. 유형 5종, 난간·창문 반복 감소. 정교한 아트는 더 필요.
3. 다양한 탐험 장면: **부분 충족**. 시장/마당/들판/구유 공간과 3개 연출.
4. NPC 자연스러움: **기능 충족, 아트 미완료**. 움직임·충돌 검증, 인간 연기 품질은 시안.
5. 주요 인물 품질: **미완료**. 마리아·요셉·아기 최종 모델 없음.
6. 팝업 이상의 사건: **부분 충족**. 카메라·빛·자막 결합, 주요 인물 연기 없음.
7. 실제 배경음악: **충족**. 합성 악곡 출력 측정.
8. 장소별 소리: **구현/부분 검증**. field/wonder 상태와 ducking 확인. 모든 위치 청취 검수는 남음.
9. 모바일 정상 작동: **최종 검증 대기**. 실제 휴대폰 미확인.
10. 첫 방문 조작: **개선/검수 대기**. 기존 탭·키보드 안내와 방향 패드, 접는 목적지 메뉴.
11. 기존 기능 보존: **코드·CPU 검사 통과**. 최종 11월드 브라우저 회귀는 대기.
12. 추정의 사실화 방지: **문서·자막에 구분 적용**. 역사적 초상/정확한 출생 건물이라고 주장하지 않음.
