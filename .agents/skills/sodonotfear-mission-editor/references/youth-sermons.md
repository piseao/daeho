# 청년 설교 작성 기준

## 대상과 목적

신앙과 일상 사이에서 고민하는 청년, 학업·취업·관계·미래가 불확실한 청년, 실패·비교·죄책감·외로움으로 지친 청년, 교회와 신앙에 질문이 있는 청년, 선교와 이웃의 섬김을 고민하는 청년을 염두에 둔다. 청년을 문제 있는 세대로 일반화하지 않는다. 교회를 오래 다닌 독자와 처음 성경을 접하는 독자 모두 이해할 수 있게 쓴다.

## 원고를 쓰기 전

각 원고에 다음을 먼저 정하고 글에서 확인할 수 있게 한다.
- **성경 본문과 사용 번역본:** 본문 전체를 직접 확인한다. 인용할 때 저작권을 존중하고, 번역을 확인하지 못한 문장을 해당 번역본의 직접 인용으로 표시하지 않는다.
- **문맥:** 앞뒤 논지, 화자·대상·상황, 본문이 성경 전체에서 놓이는 자리를 살핀다.
- **중심 메시지:** 본문에서 나온 한 문장으로 정리한다.
- **삶의 질문:** 독자가 실제로 겪을 법한 구체적 고민을 정한다. 경험담을 꾸며내지 않는다.

최근 청년 설교의 본문·중심 메시지·적용을 비교한다. 같은 본문을 다시 다루는 것이 유익하면 새로운 초점과 이유를 분명히 하고, 제목만 바꾼 반복은 피한다.

## 해석과 개혁주의 방향

하고 싶은 이야기에 구절을 끼워 맞추지 않는다. 하나님의 성품과 행하심, 인간의 죄와 한계, 그리스도의 구원과 은혜를 본문에 충실하게 설명한다. 모든 본문을 같은 공식으로 처리하지 않는다. 그리스도와의 연결은 문맥과 성경 전체의 흐름 안에서 설명하고 근거 없는 상징 해석을 피한다.

순종·봉사·선교 참여는 구원을 획득하거나 하나님께 인정받기 위한 성과가 아니라 받은 은혜에 대한 응답으로 설명한다. 취업·돈·관계의 성공을 믿음의 필연적인 보상처럼 약속하지 않는다. 어려움이 계속된다는 이유로 독자의 믿음을 단정하지 않는다. 지역교회, 말씀과 기도, 성도의 교제와 실제적 돌봄에 연결한다.

## 구성과 길이

설교 본문 약 **3,000~5,000자**를 기본으로 한다. 성경 본문 안내·별도 나눔 질문·사진 출처만 길게 붙여 본문의 분량을 대신하지 않는다. 논지에 맞춰 유연하게 구성하되 다음 요소를 포함한다.

1. 청년의 삶의 질문으로 시작하는 도입
2. 성경 본문의 배경과 흐름
3. 본문에 근거한 핵심 설명
4. 그리스도와 은혜를 바라보는 메시지
5. 일상에서 돌아보고 실천할 구체적인 적용
6. 결론과 기도문
7. **소그룹 나눔 질문 3개**

직접 확인하지 않은 설교 시간은 표시하지 않는다. 매번 같은 감정적 결론을 반복하지 않는다. 적용 질문은 개인 사연을 공개하도록 강요하지 않는 방식으로 쓴다.

## 균형 있게 다룰 주제

- 성취와 비교 속에서 그리스도 안의 정체성
- 실패한 날에도 의지할 은혜, 죄책감·회개·용서
- 미래와 섭리, 공부·일·소명과 일상의 섬김
- 외로움과 공동체, 관계에서의 진실함과 사랑
- 돈·소비·감사와 청지기의 삶
- 의심과 질문을 가지고 말씀 앞에 서는 태도
- 선교를 향한 마음과 작은 순종
- 기술·SNS 속에서 마음을 지키는 삶
- 지친 청년의 쉼과 예배

## 표시와 작성 명의

첫 부분에 독자가 읽을 수 있는 문장으로 **‘AI 작성 도움을 받은 설교문 초안’**을 표시한다. 해당 정보를 숨겨진 메타데이터에만 넣지 않는다. 기존 작성 명의를 따르되 실존 목회자의 이름·설교 스타일을 빌리거나 실제 받지 않은 감수·교회 승인을 표시하지 않는다.

마지막에 다음 취지의 안내를 남긴다: “성경 본문을 직접 읽고, 이 설교문 초안의 해석과 적용을 소속 교회의 목회자와 함께 살펴보세요.” 공식 감수 완료를 주장하지 않는다. 이 안내와 초안 표시는 게시 중단 조건이 아니다. 사용자가 게시를 요청했으면 검증·배포까지 진행한다.

자료 사진 속 인물을 실패·죄·중독이나 간증의 당사자로 연결하지 않는다. 따뜻한 자연과 공간, 책·길 같은 사진으로 논지와 분위기를 돕는다.

## 카테고리와 확인

카테고리명은 정확히 **‘청년 설교’**다. 다른 유사 분류를 중복 생성하지 않는다. 첫 청년 설교 작업에서 기존 목록을 보존해 추가하고, 관리자 선택과 공개 글의 필터를 확인한다. 현재 사이트는 공개 글이 있는 카테고리만 독자용 필터에 표시하므로 카테고리만 추가했다고 공개 필터에 보인다고 보고하지 않는다.
